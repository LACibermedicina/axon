Princípios de engenharia

Procedência obrigatória

Toda saída da API é embrulhada num envelope com provenance, version, seed e disclaimer. Todo parâmetro novo entra com etiqueta no comentário da linha.

Núcleo puro

h() e Ith() não têm estado global nem efeitos colaterais. Unidades CGS no núcleo; conversão só na fronteira pública.

Domínio é contrato

Fora de 1–16 µm ou 0,3–1,5 mm, Ith_checked levanta DomainError e a API responde 422. Estender o domínio exige refazer a convergência.

Funciona offline

O frontend tem um port numericamente idêntico do núcleo: o desktop roda de um pen drive, sem rede (Decisão 6 do livro). A API acrescenta IA e salas.

Núcleo nodal (Caps. 3, 6 e 7; Anexo G)

Cadeia McNeal-like de N = 41 nós, membrana passiva, regime linear. Como a resposta é linear na corrente, o limiar sai por divisão: Ilim = Vlim / h(D, r).

Vₑ(xₙ) = −ρₑ·I / (4π·√(xₙ² + r²)), xₙ = (n − 20)·L, L = 100·D
C·dVₙ/dt = −g·Vₙ + Gₐ·(Vₙ₋₁ − 2Vₙ + Vₙ₊₁) + Gₐ·(Vₑ,ₙ₋₁ − 2Vₑ,ₙ + Vₑ,ₙ₊₁)
Gₐ = π·d²/(4·ρᵢ·L) · C = Cₘ·π·d·Lₙ · g = g_L·π·d·Lₙ · d = 0,7·D
def h(D, r, pw=100e-6, rho_i=RHO_I, N=41, dt=1e-6, rho_e=RHO_E, ln=LN):
    Dc = D*1e-4; d = .7*Dc; L = 100*Dc                 # µm → cm; [LITERATURA refs. 2, 35]
    Ga = np.pi*d**2/4/(rho_i*L); ar = np.pi*d*ln; C = CM*ar; g = GL*ar
    x = (np.arange(N)-N//2)*L
    Ve = -rho_e/(4*np.pi*np.sqrt(x**2+r**2))           # fonte pontual, corrente unitária
    drv = np.zeros(N); drv[1:-1] = Ga*(Ve[:-2]-2*Ve[1:-1]+Ve[2:])
    V = np.zeros(N); vm = 0
    for k in range(int((pw+300e-6)/dt)):               # pulso + cauda de 300 µs
        Vp = np.pad(V, 1, mode="edge"); lap = Vp[:-2]-2*V+Vp[2:]   # Neumann
        V = V + dt/C*(-g*V + Ga*lap + (drv if k*dt < pw else 0)); vm = max(vm, V.max())
    return vm

def Ith(D, r, **kw): return VTH / h(D, r, **kw)        # A

Frontend 3D

Motor de zoom semântico

Cinco grupos Three.js (L1…L5) com visibilidade exclusiva. A roda acumula intenção: ao exceder 0,55×/2,2× da distância nominal três vezes, setLevel(±1) dispara um fade de 260 ms, troca o grupo, interpola a câmera e emite axon:scale. Rótulos são div projetados por quadro (sem texto em textura).

Gerenciador de janelas

Estados: aberta → em foco ⇄ minimizada → fechada. Arraste pela barra de título (pointer capture), redimensionamento CSS com ResizeObserver que chama draw(), duplo clique fora de .win/.dock/.side/.menubar fecha a janela em foco. Em telas ≤ 900 px só uma janela fica aberta.

Biblioteca externa: Three.js r128 via cdnjs. Para operação 100 % offline, coloque three.min.js em frontend/vendor/ e troque a tag; scripts/build_standalone.py gera um HTML único.

IA contextual (App 7 e App 8)

  • Chaves lidas apenas do ambiente do container; nunca logadas nem devolvidas (/api/ai/status lista só nomes de provedores).
  • O prompt do Axon Bot proíbe inventar números, prescrever parâmetros e afirmar eficácia; números entram só pelo campo context, vindos do núcleo.
  • O tradutor preserva símbolos, unidades, equações e etiquetas; a interface usa dicionários estáticos (pt, en, es, zh, hi).

Implantação na VPS

A VPS é compartilhada com outras aplicações LACibermedicina. Por isso o axon segue a mesma regra das demais: nenhuma porta abaixo de 1024 e nenhuma porta ocupada; o HTTPS é atendido pelo proxy que já existe no host.

  1. DNS: registro A de axon.m3d.pro → IP da VPS.
  2. Chave de deploy: gere um par SSH; a pública vai para a VPS, a privada para o secret VPS_SSH_KEY.
  3. Provisionamento (root): git clone https://github.com/LACibermedicina/axon /tmp/axon && sudo bash /tmp/axon/scripts/setup_vps.sh voce@dominio /caminho/deploy.pub
  4. O script instala Docker, cria o usuário deploy (sem sudo, grupo docker), copia para /opt/axon, gera .env (chmod 600) com segredos aleatórios, escolhe HTTP_PORT livre ≥ 20180, sobe a stack e cria o vhost nginx/apache com certbot --redirect (rollback se o vhost quebrar o proxy).
  5. UFW: só ajustado se já estiver ativo (garante 22/80/443). Traefik próprio apenas em VPS dedicada: AXON_TRAEFIK=1.
# perfis opcionais
sudo AXON_PROFILES=collab,data bash scripts/setup_vps.sh voce@dominio
# operação
cd /opt/axon && docker compose ps && docker compose logs --tail=80 api web
curl -fsS http://127.0.0.1:$(grep ^HTTP_PORT= .env | cut -d= -f2)/api/health

  • Nenhum parâmetro novo sem etiqueta de procedência no comentário da linha.
  • Nenhum resultado exportado sem versão do código e semente.
  • Mudou um valor da tabela de regressão? Atualize os testes, o reference.js (rode run_reference()) e o CHANGELOG na mesma alteração.
  • Estender o domínio verificado exige refazer a convergência no novo domínio.
  • Versionamento SemVer com sufixo de estágio (-alpha, -beta); CHANGELOG no formato Keep a Changelog.

Solução de problemas

Palco 3D vazio

WebGL desativado ou bloqueio do cdnjs. Verifique chrome://gpu; em rede restrita, use a cópia local de three.min.js.

“HTTP_PORT ocupada por outro serviço” no deploy

Outro serviço tomou a porta. Rode sudo bash scripts/setup_vps.sh <email>: ele escolhe uma porta livre e atualiza o vhost.

IA sempre em modo offline

Confira /api/ai/status. Se configured estiver vazio, rode o workflow manualmente (Actions → ci-axon → Run workflow) e verifique o log do passo sync-ai-env (ele avisa se faltarem VPS_HOST/VPS_SSH_KEY).

Certificado não emitido

O DNS ainda não aponta para a VPS. Depois de propagar: sudo certbot --nginx -d axon.m3d.pro.

Teste de regressão falhou após mudança

Se a mudança foi intencional, atualize testes, reference.js e CHANGELOG juntos. Se não foi, procure alteração na ordem das operações de h().
